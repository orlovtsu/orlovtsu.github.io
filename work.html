04 / Cybera · Applied NLP

Entity resolution
at distributed scale.

Connect unstructured records with learned representations, retrieval, and reproducible distributed execution.

What I built

Designed and deployed an entity-resolution pipeline for unstructured data using transformer embeddings, Siamese neural networks, and retrieval. GPT-assisted labeling and normalization reduced manual preparation.

Execution and evaluation

Scaled execution with Docker, multiprocessing, GPU acceleration, and a 24-node GCP virtual-machine cluster. The reported classification accuracy was 92% on the project evaluation.
